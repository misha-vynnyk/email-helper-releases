# FlexiBuilder Pro — Downloads

Готові збірки десктоп-застосунку FlexiBuilder Pro (macOS / Windows). Дивіться вкладку **Releases** праворуч — там актуальна версія.

### ⚠️ Білди не підписані
Ні macOS, ні Windows білди не мають сертифіката підпису — ОС попередить про невідомого розробника.

- **macOS**: правий клік на `.app` → «Відкрити» → підтвердити. Або: System Settings → Privacy & Security → «Open Anyway».
- **Windows**: SmartScreen покаже «Unrecognized app» → «More info» → «Run anyway».
